# Übersicht

**pe-mixer** ist ein lokales, regelbasiertes Audio-Engineering-Expertensystem zur automatischen Erstellung sauberer Grobmixe (Rough Mixes) aus Multitrack-Probenaufnahmen und Live-Mitschnitten (z. B. von Soundcraft Ui24R Mixern).
